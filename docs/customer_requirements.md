\# Besoins client - Power Window ECU



Contexte : projet académique inspiré de la norme ISO 26262 (hypothèses de projet).



| ID | Besoin client |

|---|---|

| CUST-01 | Le conducteur et le passager peuvent monter et descendre leur vitre avec un bouton. |

| CUST-02 | La vitre ne doit pas blesser un passager : elle doit détecter un obstacle et réagir. |

| CUST-03 | Le conducteur peut commander la vitre du passager depuis sa porte. |

| CUST-04 | Le système doit se mettre dans un état sûr en cas de défaut de communication. |

| CUST-05 | Un technicien en atelier doit pouvoir lire les défauts et la version du logiciel. |

| CUST-06 | Le code doit respecter les règles de qualité automobile (MISRA C). |
